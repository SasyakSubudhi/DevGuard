# Submission checklist

- [ ] Every team member is registered on the hackathon platform.
- [ ] IBMid uses the hackathon registration email.
- [ ] Bob IDE is installed and signed into the hackathon-provisioned account.
- [ ] Bob IDE version is supported and the 40-Bobcoin allocation is visible.
- [ ] The end-to-end Bob workflow completes on the sample incident.
- [ ] Both manual and Bob-assisted timings are recorded in `docs/METRICS.md`.
- [ ] All relevant Bob task-session summaries are saved in `bob_sessions/`.
- [ ] No secrets, client data, personal data, or unauthorized datasets are present.
- [ ] Public repository includes working source, setup instructions, and Bob evidence.
- [ ] Demo video shows failure, parallel investigation, cited cause, fix, regression test, and measured impact.
- [ ] Pitch deck explains the problem, workflow, architecture, measurable result, and Bob's core role.
- [ ] Submission form, repository URL, video URL, and deck/PDF are checked before the deadline.
