# IBM Bob task evidence

Save every relevant Bob IDE task-session consumption screenshot in this folder as a PNG.

Naming convention:

`teamname_taskNN_short_description_summary.png`

Recommended evidence for this project:

1. `teamname_task01_parallel_investigation_summary.png`
2. `teamname_task02_fix_and_regression_test_summary.png`
3. `teamname_task03_validation_and_review_summary.png`

In Bob IDE, open **Tasks**, select the relevant task, select its task header, then capture the session consumption summary. Replace `teamname` with the exact team name used in the submission. Do not include credentials or personal information in screenshots.
